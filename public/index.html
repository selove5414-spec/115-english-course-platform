如何設定 Notion API 連線（在 .env.local 中設定）

  1. 前往 Notion Integrations 建立整合金鑰（格式如 secret_xxxx...）。
  2. 在 Notion 中建立或開啟您的資料庫，點擊右上角 ... ➔ 連線至 (Add connection) 授權剛建立的整合。
  3. 將資料庫網址中的 32 位代碼複製為 Database ID。
  4. 於專案目錄 .env.local 填入 NOTION_API_KEY 與各資料庫 ID，或在 Vercel 專案 Settings ➔ Environment Variables 中填入即可！
